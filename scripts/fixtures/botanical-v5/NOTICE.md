# Botanical Review photos

These eight small JPEG derivatives are species illustrations for synthetic review
records, never evidence of a real owned specimen or a verified cultivar. They are
intentionally not native-range, provenance, occurrence or taxonomic authority data.

`media-manifest.json` gives each source description page, creator, original public
preview URL, selected reuse licence, licence link, inspection date, modification
notice and the SHA-256/size of the included derivative. Each was resized to at most
640px and recompressed with EXIF removed. CC0 works retain voluntary credit; CC-BY
works retain attribution, licence and modification notice in the asset metadata.
Licence verification uses the individual Wikimedia Commons file descriptions,
not the site's general text licence or a category assumption. No GBIF photograph
was used. Packaged fixture photos are read offline by the seeder and uploaded into
Review's protected attachment storage; external assets are metadata-only references.

These files live outside the production backend/frontend Docker build contexts.
Integration tests and the guarded Review seeder mount this fixture directory read-only.
No seeder downloads files, creates external previews, loads occurrences or prefetches tiles.

the adjacent machine-readable manifest. The application code licence does not
