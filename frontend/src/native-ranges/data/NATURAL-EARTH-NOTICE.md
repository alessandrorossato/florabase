# Natural Earth presentation geometry

Made with Natural Earth. **Public domain**; attribution is optional under the
[source terms](https://www.naturalearthdata.com/about/terms-of-use/).

Dataset: 1:110m Admin 0 map units **5.1.1**, official repository release **v5.1.2**.
`world-110m.json` is derived offline by `scripts/generate_native_range_geometry.py`
from the pinned official source, preserving code-based territory drawing paths.
See `docs/native-ranges-explore.md` for review, hashes, omissions and political-boundary
limitations. Botanical native-range assertions remain operator-managed Florabase data.
