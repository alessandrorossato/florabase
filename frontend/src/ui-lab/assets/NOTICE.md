# Botanical Review photos

These eight small JPEG derivatives are species illustrations for synthetic review
records, never evidence of a real owned specimen or a verified cultivar. They are
intentionally not native-range, provenance, occurrence or taxonomic authority data.

`media-manifest.json` gives each source description page, creator, original public
preview URL, selected reuse licence, licence link, inspection date, modification
notice and the SHA-256/size of the included derivative. Each was resized to at most
640px and recompressed with EXIF removed. CC0 works retain voluntary credit; CC-BY
works retain attribution, licence and modification notice. Licence verification
uses the individual Wikimedia Commons file descriptions, not the site's general
text licence or a category assumption. No GBIF photograph was used.

These files are frontend assets used only for synthetic UI Lab records and are
bundled with the UI Lab. They are not application-owned collection media. The
original fixture images and manifest remain available to the Review seeder, which
reads them offline and uploads them into Review's protected attachment storage.
External assets remain metadata-only references. No seeder downloads files,
creates external previews, loads occurrences or prefetches tiles.

Original creators: Merstel007; Daria Sitnikova; Caroline Léna Becker; Homoarborea;
Cliff Hutson; Lena Jaginyan; AnRo0002. Per-file CC0/CC-BY terms and checksums are
in the adjacent machine-readable manifest. The application code licence does not
replace or relicense these photographs.
