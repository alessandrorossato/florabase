## 3. Detailed Pre-RC Verification of Step 10 (Session Expiry, Draft Retention & Backend Outage)

### 3.1 Baseline Audit Defect (`P0-GCORE-10`) and Frozen Remediation (`173b9f6eed7979e4bc0793af88a55b4de7af1eeb`)

- **Audit defect observed on `main` (`c555baa` / `fdc75e8`):** When an authenticated session expired (`HTTP 401`) while the user was editing a record, `AuthProvider.sessionExpired()` transitioned `auth.state` to `{ status: "unauthenticated" }`, causing `ApplicationShell` and 14 domain editor components to return `null` and unmount the active dirty form.
- **Frozen remediation (`fix/session-expiry-draft-recovery`, `HEAD` `173b9f6eed7979e4bc0793af88a55b4de7af1eeb`, `tree` `16f49ed8fed031105f8296fda8bcd4f4dd027686`):**
  1. `expireAuthenticatedSession` transitions immediately out of `status: "authenticated"` to `{ status: "unauthenticated", retainedIdentity: { user_id, login_name, display_name }, message: "Your session expired. Sign in again to continue." }`, clearing `csrfToken` in memory (`activeCsrfToken(auth.state) === ""`) and locking the request gate (`syncAuthRequestGate({ locked: true, advanceEpoch: true })`).
  2. While locked, `requestJson()` synchronously rejects all protected requests with `AuthRequestLockedError` **before calling `fetch()`**, aborts in-flight requests from the superseded epoch with `StaleAuthEpochError`, and notifies `EvidenceTiles` to abort in-flight tile requests and cancel pending `setTimeout` retry timers.
  3. `ReauthenticationDialog` opens as a native top-layer `<dialog id="reauth-dialog">` (`showModal()`, `dismissOnBackdrop={false}`, no-op `onClose`) over any open `dialog.edit-workspace-modal` while setting `hidden`, `inert`, and `aria-hidden="true"` directly on `main > .application-shell`.
  4. Reauthentication executes `POST /api/v1/auth/login` (`LoginResponse.csrf_token`) followed by `GET /api/v1/auth/session` (`SessionResponse.user_id`) inside `enqueueCookieOp`:
     - **Same `user_id`:** Unlocks the request gate at a new epoch with the fresh CSRF token while keeping `workspaceKey` unchanged; restores focus to the invoking editor control (`Save changes`) without auto-replaying the failed mutation.
     - **Different `user_id` (or explicit `"Discard unsaved changes and sign out"`):** Increments `workspaceKey` in the same React commit, synchronously unmounting the previous owner's React subtree with zero transient visible frames.
