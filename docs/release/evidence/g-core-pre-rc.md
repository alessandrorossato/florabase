All source-level AUTH findings are closed, and the exact source `08c0bb353d98ac752a5828fe8f207fe44ad789cd` is eligible for WF-04 integration.
- **Closed findings & enforced invariants:**
  1. **Session expiry, retained drafts & manual retry (G-CORE Step 10):** On HTTP `401` from protected JSON APIs or current-epoch occurrence tiles (`notifyProtectedUnauthorized`), `AuthProvider` transitions immediately to `status: "unauthenticated"` with `retainedIdentity`, clears in-memory CSRF authority (`activeCsrfToken(auth.state) === ""`), locks the request gate, and advances the auth epoch. Active dirty editor DOM stays in memory inside `main > .application-shell` marked `hidden`, `inert`, and `aria-hidden="true"` behind a native top-layer `<dialog id="reauth-dialog">` (`showModal()`, `dismissOnBackdrop={false}`, no-op `onClose`). Neither reauthentication nor backend outage recovery ever auto-replays a failed mutation: the user must explicitly retry `Save` once unlocked or once the backend recovers.
  2. **Same-owner recovery, CSRF rotation & cross-owner isolation:** Reauthentication calls `POST /api/v1/auth/login` (`LoginResponse.csrf_token`) followed by `GET /api/v1/auth/session` (`SessionResponse.user_id`) inside the serialized lifecycle queue. Same `user_id` unlocks the existing workspace capability at a fresh epoch with the rotated CSRF token and restores focus to the invoking control. Different `user_id`, logout, explicit discard, cold login, restoration, or provider teardown/replacement permanently revokes capabilities (`record.revoke()`, never revived across `A -> B -> A` transitions) and increments `workspaceKey` in the same React commit so prior-owner UI is destroyed synchronously with zero transient visible frames.
  3. **R1 closure & unconfirmed historical candidate events:** Mandatory owner-bound `ProtectedRequestCapability` propagation across all `32` domain API modules and permanent revocation barriers close R1 by construction, independent regression (`QA-1`), and killed mutation controls. **The two historical R1 calibration candidate events remain unconfirmed**; closing R1 does not establish what occurred in those two earlier candidate events.
  4. **All five R2 corrections closed:** `NativeRangesScreen`, `TerritoryInspector`, `TaxonomyScreen`, `DashboardSearch`, and `SavedViews` were remediated under the owner-bound request boundary and independently verified by Opus in disposable Chromium on predecessor `9bd4548`.
  5. **Protected media, downloads & occurrence tiles:** Protected images render exclusively via `blob:` URLs through `useProtectedImage`; CSV exports/templates/examples use `downloadProtectedFile` (RFC 5987 `filename*` parsing, binary byte fidelity, single-active-download mutex); occurrence map tiles use `EvidenceTiles` with `notifyProtectedUnauthorized(originatingEpoch)`, sibling abort, retry-timer cancellation, and unlock redraw; `openProtectedTab` (`"Open original image"`) allocates a popup synchronously on click, nulls `opener`, loads a `blob:` URL, and closes the tab on any auth lock within its 60-second cleanup window (accepted by SOL as bounded cleanup behavior).
