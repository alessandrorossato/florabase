No API/schema, migrations, provider calls, dependencies, global navigation, dark mode or persistent
UAT changes belong to this increment. The existing v4 fixture covers recorded/unknown/zero Sowing
states, direct and Sowing-derived Plants, managed group, locations, Journal, media and planned work.
No fixture code extension is needed.

Contextual propagation entry was also inspected directly: SeedLotSowingWizard's Sowing fields use
page mode while retaining the genuine second-stage seed-usage decision and one atomic endpoint;
SowingDescendantWizard uses page mode while retaining explicit origin, optional result count and
resulting-Sowing lifecycle. These are the same existing payload/validation mechanisms, not a new
propagation design. Shared field groups and conditional required markers remain authoritative.
