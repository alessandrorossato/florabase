# Labels / Settings / navigation review evidence

`final-*` files prove the current botanical-only physical content, contextual QR destination dialog
and Theme icon cycler. Only the current final evidence is retained for this handoff. Superseded interim screenshots and
probes were removed after review.

- `final-browser-evidence.json`: seven actual tab-zoom boundaries; 21 screen/print cell/QR geometry
  probes; dialog persistence/composition/focus checks; 12 optional-name and 12 clipping stress cases.
  It also records the native connected-browser checks and actual one-page A4 sample checks.
- `final-qr-decode.json`: independent ZXing-C++ 3.1.1, 48 checks for all four categories/three sizes
  using actual print-media PDF rasterization at 300/200 dpi, blur and complete physical labels.
- `final-physical-*` and `final-qr-*`: complete label/QR rasters from those actual print samples.
- `final-labels-*`, `final-qr-dialog-*`, `final-theme-*`, `final-mobile-more.png`: current workspace,
  modal and all monitor/sun/moon states at requested widths/zooms.
- `final-names-*`, `final-stress-*`, `final-workspace.png`: name combinations, real clipping warnings
  and balanced print preview. Botanical stress/name combinations use read-only intercepted fixtures;
  those test responses never change source records.
- `final-preservation.json`: exact disposable retirement and domain/fixture/media retention. Protected
  runtime/Git identity matches; the live UAT raw digest differs, authentication activity is observed,
  and complete data equivalence/exact cause remain unproven.

Headless regression uses DOM control/keyboard activation and an isolated extension for real tab
zoom; native interaction is checked separately in the connected browser. Temporary QA PDFs are
not a product PDF feature. The first harness's screen-media PDFs were replaced before decoding;
accepted samples use explicit print media and A4. No physical printer/system dialog is certified.
