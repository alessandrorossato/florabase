## Theme, zoom and interaction scope

All 27 primary states are targeted at three CSS viewports × Botanical Light/Dark. Herbarium/Mineral Light/Dark sample Seeds, Calendar, Taxonomy fallback, Media and Native ranges on desktop. All six variants sample the Seeds drawer and Orders direct editor on mobile. No full Cartesian state matrix is claimed.

Actual zoom shortcut Ctrl+Plus left 1440×844, DPR 1 and visual scale 1 unchanged. 125%/150% actual browser zoom is **MISSING**, never replaced by viewport scaling. Screen reader, physical touch, forced colors, reduced-motion emulation and software-keyboard occlusion remain manual. Tooltip visibility was not established in this run. Escape/focus return for the filter drawer and cancellation of Media deletion were observed in [interaction evidence](interaction-evidence.json).

No page-level horizontal overflow was measured in selected acquisitions. This does not prove internal panels, every focus target or 320px reflow fit. Long synthetic names, cultivar labels, quantity uncertainty, partial dates and geographic paths come from v5. See full-page Seed detail and mobile directory/editor examples.

The browser API emits reduced content JPEGs (for example 1440×844 CSS → 1425×835 raster, 390×844 CSS → 375×812 raster). These are genuine browser captures; no upscaling or manufactured pixel-perfect viewport claim. Raster sizes are per capture in the index.
