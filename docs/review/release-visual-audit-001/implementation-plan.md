## Scope by finding

F01 → B0; F02 → A then narrow Collection row part of C; F03 → A; F04 → Media dependency;
F05 → C/D; F06 → B; F07 → C/D; F08 → optional D after higher priorities; F09 → A0 before cosmetic header alignment.
Do not block a small F01 correction on a full visual redesign.

## Per-wave acceptance

Provide before/after screenshots of changed consumers and an unchanged sibling in Botanical Light/Dark,
repeat risk samples in the other palettes, and record real interaction behavior. Keep domain tests
around existing boundaries rather than writing tests that simply mirror CSS. Any geometry change
must preserve focus/long content and application-provided unknown values. Protected environments,
API contracts and backend persistence are outside these UI waves unless separately authorized.

## Stop and review

The current phase ends at operator review. No staged files, commits, push, PR, merge, broad component
refactor or canonical FULL run. A later implementation request selects a wave and its acceptance
scope; it does not silently authorize all five waves or delivery.
