# Existing component ownership and proposed convergence

This is a source inventory of the delivered tree, not a list of new components to build.
[Machine-readable consumers](component-consumers.json) names actual non-test TSX files referencing
each primitive. A reference means usage/ownership, not proof of a defect or migration requirement.
Paths below are relative to `frontend/src/`. Tokens remain in `styles/tokens.css`; common layout
lives in `styles/foundation.css` and `styles/normalization.css`. Typography, spacing and geometry
have one source across the six theme variants.

## Implemented contracts to retain

ThemeControl currently cycles appearance with a visible accessible name that states the next mode;
palette and explicit System/Light/Dark radios live in Settings. The earlier design proposal's footer
chooser is historical, not proof that the delivered cycle button is a defect. Keep this distinction
in any later control decision.

TaskDialog currently focuses the first eligible control. The new safe-focus requirement is proposed
because of a reproduced destructive caller; returnFocusTo already serves a different purpose.
A general form library, menu manager, design-system package or new table framework would duplicate
current mechanisms. Do not introduce one in these waves.

Consumer verification covers real behavior: selection vs opening, live filter/query preservation,
meaningful facts, partial dates, direct edit fallback, safe dismissal and source/print restrictions.
A source reference or a screenshot alone does not certify the component's complete interaction model.
